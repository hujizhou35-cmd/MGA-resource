SEARCH → INSPECT → DOWNLOAD

直接取得可用的医学素材。

无需登录。JSON 检索返回本次选中的具体文件、直接预览与原件链接、SHA-256 和完整来源。页面和 Agent 使用同一检索核心。

从一次请求开始

curl 'https://mga-resource-mainly-for-agent.pages.dev/v1/search?q=mouse&limit=5'

复杂条件使用 POST：

POST /v1/search
Content-Type: application/json

{
  "query": "小鼠",
  "filters": {"format": "svg"},
  "mode": "explore",
  "seed": "my-study-01",
  "limit": 10
}

使用返回文件

  1. 读取 query_plan，确认实际解析的对象与硬条件。
  2. 查看 results[].preview.url 的图像，判断是否适合当前任务。
  3. 下载 results[].download.url，核对 download.sha256。每个链接直接指向文件，不需要解压图库或跳到原始素材网站。
  4. 保留 selected_source.provenance 中的许可、作者、来源和署名，以及本次修改说明。需要其他同家族变体时读取 metadata_url。

筛选、探索与分页

filters 支持 source、license、category、format、structure、content_type、species、state、view、role、object、depiction_kind、color_mode、palette_traits、representation、detail、realism、series、transparent、asset_id、family_id、file_sha256。字段列表表示其中任一种；不同字段同时满足。未知信息不能满足硬筛选。

模式为 explore、design 或 exact。为同一项目保留稳定 seed，新项目可改变 seed 探索候选；这不会放宽科学条件。preferences 只表示偏好。project.selected 可保留已选文件；history.adopted 只记录真实最终采用，必须带 status: "adopted"。

下一页沿用原请求并加入 next_cursor 的值作为 cursor。目录、规则、条件或种子改变后，旧 cursor 会拒绝使用。页大小1–20。

文字与科学含义

原件保持不变。选中素材后在工作副本上按需清理无关文字和引线；不能一律删除全部文字、箭头和线条。保留必要比例尺、方向、科学符号及机制关系，并实际查看编辑结果。text_content 的 unknown 表示未确认，不表示没有文字。

医学对象插图可带标签；完整研究流程模板、报告、结果图表与纯文字分子名牌不属于本库正式内容。历史 Servier CC BY 3.0 来源和现行 FAQ 冲突说明保留在项目资料与来源记录中。

错误与免费额度

400表示请求或cursor不合法；200且results为空表示无匹配；503表示暂时不可用或免费额度用尽，稍后重试。不会将服务失败伪装成零结果，也没有付费回退。静态预览和原件可以继续直接访问。
