Use GET or POST /v1/browse without a query. Pass filters.category to browse a category; set unclassified to true for families with no assigned category.

2. Inspect, download and cite

  • Check query_plan for parsed requirements and preview.url for the actual illustration.
  • Download download.url and verify download.sha256. The exact variant may differ from the first file in the family.
  • Keep selected_source.provenance and record any edits. Use the metadata_url or full response for more evidence.
  • Use response_profile: compact when you only need candidate inspection and delivery fields.
  • 检查 query_plan 的实际要求，然后查看 preview.url 的图。
  • 直接下载 download.url 并核对 download.sha256。不要替换成家族里的第一件文件。
  • 保留 selected_source.provenance，另记修改；进一步证据使用 metadata_url 或完整响应。
  • 只需要看图和取件时，使用 response_profile: compact。

3. Reuse projects and page through results

Pass next_cursor as cursor with the same query, filters, project, seed and history. A new seed rotates suitable candidates in explore or design; exact keeps fixed ranking. Design applies project.style. Project pins only stay when they meet current constraints.

node agent-example.mjs search mga-project.json "mouse" candidates.json
node agent-example.mjs adopt mga-project.json candidates.json 2 selected

Review the preview before running adopt. The example verifies file bytes, saves credit notes and records explicit adoption. Browser projects can be exported and reimported. Requests are limited to 16 KiB and 1–20 results per page.

Errors and scientific limits

200 with an empty results array means no match. 400 means invalid input or a stale cursor. For 503, honor Retry-After. The largest original files are hosted on GitHub Releases and may require a direct download instead of browser cross-origin fetch.

Unknown text status is not absence of labels. Modify a working copy only when needed and preserve scientific meaning, scale and attribution.
