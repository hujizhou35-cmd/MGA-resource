# 精选素材的透明、背景与缩小检查

对 48 件精选中已经有本地精确 RGBA 小预览的 9 件进行了实际检查；其余 39 件没有用白底联系表裁图来冒充透明预览。本轮没有新下载、云任务、清理背景、改色、裁切原件或改目录。逐件证据见 [检查记录](../data/curated-reviews/preview-composition-42289434868.json)。

检查画布统一使用白色 `#ffffff`、深色 `#182333`、16 像素棋盘和穿越参考线；大图最长边 256 像素，小图最长边 96／48 像素。保持原预览纵横比和空白，仅缩小显示副本。另做最长边 208 像素、格间距 12 像素的白底／深底邻接板，不画科学箭头或因果关系。

| 样本 | 实际观察 | 使用限制 |
|---|---|---|
| Test Tube Rack | 管间透明，管内白色结构保留；深底上架横梁对比降低。 | 48 像素可作整体图标，不能读单管细节；不要删白色管体。 |
| Zebrafish brain outline | 半透明灰区明显透出棋盘；深底下灰区变暗，白色分区仍亮。 | 背景会改变明暗关系；48 像素细分区线不可可靠读取。 |
| Group of People | 深底显示出清楚的白色外缘。 | 这是现有预览的实际效果，不能擅自当脏边删除；48 像素只能表示人群整体。 |
| Lysosomes | 外部透明，主体与偏右下阴影保留。 | 48 像素不适合比较内部小颗粒。 |
| Autolysosome | 黄绿两圆在不同底色下可辨；深绿边缘对比有所变化。 | 缩小后只能作概略结构，不能据此判机制细节。 |
| centrifuge user | 大图可辨人、机器及转子；深底使浅色外轮廓更清楚。 | 48 像素无法可靠看清装样操作；96 像素手与样本接触也较弱。 |
| Pipetting Female | 灰色桌面是保留的实色结构，外部透明。 | 48 像素不能可靠辨认移液器与液体接触。 |
| Tail suspension | 白底悬挂关系可见；深底灰鼠、细尾和边线明显变难辨认。 | 原样不适合本次深底；48 像素受细长纵横比影响，动物细节过小。 |
| restrain | 筒内空隙透明，黄块与鼠体保留。 | 深底筒边、尾和鼠体对比不足；48 像素不能读清保定结构。 |

实际邻接板显示：统一外接尺寸不等于统一视觉体量；细长鼠动作图显得小，圆形细胞器显得大。人群细节、平面实验场景、渐变细胞器和灰色剪影的描边、明暗与细节密度不同。**没有把这张技术拼图判为正式图稿或统一画风通过。**

深底低对比、半透明透底和 48 像素动作不可辨，都是本次指定显示条件下的**用途限制**。它们不自动触发范围排除，也不表示原件损坏。本轮冻结目录与既有范围决定均不变。

后续 API／skill 可按精确文件 SHA 暴露本报告的 `display_conditions` 和 `visual_judgment`：说明测过的背景及尺寸、建议浅底或更大显示、白色结构应保留，以及哪些细节在指定尺寸下不可辨。只报告实际测试尺寸，不据此编造统一最小可用尺寸；不把同家族其他格式自动继承为同样效果。**这是交接建议，尚未接入 API 或 skill，网站也未因此建成。**

九件实际预览中没有可供本轮评价的内嵌文字标签，所以“带标签素材的小尺寸可读性”仍未覆盖。也没有完成 48 件全覆盖、真实科研场景的相互叠压或 Illustrator 编辑验收。
