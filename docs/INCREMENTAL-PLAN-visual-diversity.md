# 颜色、画风与选材多样性增量计划

更新：2026-11-06。完整用户需求见 [补充需求](REQUIREMENTS-visual-diversity-20261106.md)。此文记录实施安排，不代表新功能或验收已经完成。

## 当前实现与差距

已有：云端采集和可恢复检查点、逐文件 SHA-256/实际格式/透明度/预览、来源许可、部分来源风格标签、明确家族归并、SQLite 中英文检索、120 条固定基准、来源抽查及精确文件绑定的 Illustrator 历史证据。

缺失：统一的文件级颜色与画风字段；变体满足条件后再归并的检索；完整的科学硬条件与视觉偏好区分；相关候选内多样性重排；项目种子、采用历史与稳定分页；这些机制的真实样例对照。

现有 `style`、格式、原生验证状态不能替代新增维度。现有家族搜索结果的第一个文件也不能默认当作颜色筛选命中的文件。

## 执行顺序

1. 保持正在运行的采集不变，修复来源/格式兼容问题；保留旧原件、检查点、汇总和报告。此前 NIH 串行任务继续，后续新任务使用有共享限速的最多四变体下载窗口。
2. 新增独立外观描述模块，在云端利用已经归档的预览与必要 SVG 结构补算。以原件哈希、分析版本和输入预览哈希缓存；来源标签与人工校正单独保留，不覆盖原件。
3. 文件/变体分别记录颜色、调色特点、表现方式、细节、写实程度、系列及依据/可信程度/复核状态。家族汇总只表示有哪些变体，不推断每个文件都具备全部属性。
4. 在共同检索核心增加变体表和结构化条件：先验证对象、必要物种/状态/视角/角色、许可与可用性，再筛选明确颜色/风格条件，再按家族归并。未知条件单列，不默认为符合。
5. 从较大的合格候选集合选择结果。探索、正式绘图和精确查询分开；轻量重排只在医学合格候选中增加差异。无硬性来源配额，不用相似度自动合并作品。
6. 加入目录版本、排序版本、查询参数、种子、历史快照绑定的确定性顺序与分页。项目记录区分浏览、试下载和最终采用；同项目保留已选文件，不强制稀缺对象换图。不以热门程度或精选/原生小库作为默认优先级。
7. 保留既有120条基准和门槛，重建受影响索引与检索报告；增加颜色边界、跨源风格、同家族不同颜色、条件/偏好、分页去重、多种子覆盖与最终采用重复、稀缺场景及新旧策略对照。报告实际结果及不确定项，不以一个布尔值替代观察。
8. 完成数据与新增验收后，再建设网页/HTTP API。网页突出直观筛选；Agent获取完整条件、命中变体、依据、版本与替代候选。后续 skill 接入项目记录和研究驱动构图；当前不恢复训练或盲测。

## 复用边界

- 原件、原始检查点和哈希全部复用；未修复的源文件继续单独记录。
- 已有科学用途/可辨认性审阅可按相同原件和预览哈希复用；不能冒充未做过的颜色或画风复核。
- 旧检索结果留作基线。新排序和筛选影响的查询必须重跑；不预绑定固定素材提高命中率。
- 五件原生验证素材只提供真实编辑证据，不构成检索白名单或永久排名加分。
- 既有免费 GitHub Actions / Releases 与后续 Cloudflare Free 方案继续；不引入托管付费搜索、向量数据库或模型。

## 参考方法与限制

- [Unsplash 搜索](https://unsplash.com/documentation#search-photos)：借鉴独立颜色参数。
- [Iconify 颜色解析](https://iconify.design/docs/libraries/tools/icon/colors.html)：借鉴颜色结构与着色能力区分，不能由外观单色推断可安全改色。
- [Icons8 画风系列](https://icons8.com/illustrations/styles)：借鉴表现方式及具体系列的双层组织，不采集其商业素材。
- [Algolia distinct](https://www.algolia.com/doc/api-reference/api-parameters/distinct)：借鉴限制同家族变体占位，先完成变体条件匹配。
- [Elastic MMR](https://www.elastic.co/search-labs/blog/maximum-marginal-relevance-diversify-results)：借鉴相关性与结果间差异的权衡，不放松医学硬条件。
- [Amazon 探索机制](https://docs.aws.amazon.com/personalize/latest/dg/create-recommender-configure-exploration.html)：借鉴给予较少使用候选机会。其通用推荐可探索较低相关候选；本项目仅在满足医学条件的候选中进行受控轮换。

## MCP 分工

Illustrator MCP负责实际绘图、编辑和有限原生验收。GitHub Actions与采集脚本负责云端获取、检查和归档。MGA-resource以同一数据模型和检索逻辑支撑静态目录、HTTP API、命令行与网页；可选专用MCP只包装这些能力。MCP不是颜色分类或防趋同机制，也不作为其前置条件。
